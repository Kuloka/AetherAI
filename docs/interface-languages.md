# Interface languages and model preferences

The desktop supports English, Russian, Spanish, Portuguese, French, German, Italian, Turkish, Polish and Ukrainian. Settings, model controls, commands, account panels and command confirmation share the interface dictionary in interface-i18n.js. The chosen language also applies to updated controls without reloading. Model names, filenames, code and assistant answers are preserved.

Manage models is available in the footer of the model menu. Preferences lists only model families, with one checkbox on the right for all versions in that family. Multiple families remain enabled together. Repeated clicks restore the whole family. The Preferences entry is hidden from settings navigation. Existing individual visibility is retained as a partial family selection until the user chooses its family checkbox.
