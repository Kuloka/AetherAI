# Interface languages and model preferences

The desktop supports English, Russian, Spanish, Portuguese, French, German, Italian, Turkish, Polish and Ukrainian. Settings, model controls, commands, account panels and command confirmation share the interface dictionary in interface-i18n.js. The chosen language also applies to updated controls without reloading. Model names, filenames, code and assistant answers are preserved.

Preferences lists expandable model families. Check or uncheck individual models on the right; multiple enabled models remain in the model menu together. Repeated clicks toggle visibility back. A family checkbox controls all its versions and becomes indeterminate for a partial selection. Enabling one model from a disabled family restores only that model. Selections survive catalog refreshes and restarting the application.

Validation includes dictionary completeness for all ten languages, native language switching in every settings section, right-aligned checkboxes, independent model selections, family selection, partial selection, restart persistence and unchanged assistant answer content.
